# Jade Loutaty — Cheffe à domicile

Site statique publié avec GitHub Pages.

- `index.html` : toute la page (textes, styles et petit script du formulaire).
- `photos/` : les photos du site. Pour en changer une, remplacez le fichier en gardant le même nom.
- Le formulaire envoie les demandes à Formspree (adresse dans le script en bas de `index.html`).
